支持的模型与接入调用说明

所有模型均挂载在当前 EasyCLIProxyAPI 内核的同一端口（默认为 8317）。无需额外启动端口，直接向 http://127.0.0.1:8317 发送标准 OpenAI 或 Gemini 请求即可。

OpenAI 兼容文生图调用示例:

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer 你的CPA密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-gemini-3.1-flash-image-landscape",
    "messages": [{"role": "user", "content": "一只可爱的赛博朋克小猫"}],
    "stream": true
  }'

OpenAI 兼容文生视频调用示例 (Veo 3.1):

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer 你的CPA密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-veo-3.1-fast-8s-landscape",
    "messages": [{"role": "user", "content": "航拍金色阳光洒在大海微波上"}],
    "stream": true
  }'
