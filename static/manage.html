支持的模型与接入调用说明

所有模型均挂载在当前 EasyCLIProxyAPI 内核的同一端口（默认为 8317）。无需额外启动端口，直接向 http://127.0.0.1:8317 发送标准 OpenAI 或 Gemini 请求即可。

OpenAI 兼容文生图调用示例:

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer 你的CPA密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-nano-banana-2.1",
    "messages": [{"role": "user", "content": "一只可爱的赛博朋克小猫"}],
    "stream": true
  }'

OpenAI 兼容文生视频调用示例 (Veo 3.1):

curl -X POST "http://127.0.0.1:8317/v1/chat/completions" \
  -H "Authorization: Bearer 你的CPA密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gflow-veo-3.1-fast",
    "messages": [{"role": "user", "content": "航拍金色阳光洒在大海微波上"}],
    "stream": true
  }'

添加 GFlow 账号
方式一：浏览器自动同步（推荐）

GFlow 登录助手 · 免费扩展，不用 F12 找 Cookie。

  1. 复制下载地址，在 Chrome / Edge 地址栏粘贴并回车，下载 ZIP 并解压。在扩展管理页开启“开发者模式”，点击“加载已解压的扩展程序”。
  2. 点击上方“复制扩展配置”，在“GFlow 登录助手”中粘贴，填写当前 Google 邮箱。
  3. 在同一个浏览器打开 flow.google.com/projects 并登录，点击扩展的“保存并同步”，回到这里刷新账号列表。

这是什么？查看源码

这是安装在 Chrome / Edge 中的免费浏览器助手，用于同步已登录的 Flow 账号。不是再次安装 EasyCPA 插件。

EasyCPA 内嵌窗口限制下载和新窗口跳转，请把地址粘贴到浏览器地址栏。

首次配置一次；之后可一键同步或每 60 分钟自动同步。配置包含管理凭据，请仅粘贴到 GFlow 登录助手，不要分享。

方式二：手动粘贴
如何获取 Cookie / Session Token？
  1. 登录 Google Flow，按 F12 → Network，勾选 Disable cache 后刷新。
  2. 点击发往当前 Flow 网站的请求，在 Headers → Request Headers 中复制 Cookie 的值，粘贴到上方。

若看到“Provisional headers”，换一条实际已完成的请求。不要复制 Set-Cookie。Application → Cookies 中若存在 __Secure-next-auth.session-token，可只复制它的 Value；找不到就用扩展。

支持 Cookie 字符串、Cookie JSON 或 Session Token。登录过期后重新同步，不要分享 Cookie。

只同步你有权使用的账号；添加时会验证登录、查询额度并可能创建项目，不会自动生成。Flow 积分和打码费用另计。
